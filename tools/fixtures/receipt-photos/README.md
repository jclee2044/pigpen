# Real receipt regression photographs

Eight unmodified photographs from [ExpressExpense SRD](https://expressexpense.com/blog/free-receipt-images-ocr-machine-learning-dataset/), provided under the MIT license with required attribution to ExpressExpense.com. The [research dataset record](https://zenodo.org/records/13688441) describes them as hand-photographed restaurant receipts. Original image bytes and SHA-256 values are recorded in `selection.json`. These are public test documents, never household production data.

Selected for actual curls, creases, wrinkles, shadows and difficult framing. They are development regressions, not an independent accuracy benchmark. Visible printed amounts were read manually; they do not establish subsequent paid tips. No generated distortions were added. Browser tests exercise the camera and real local OCR; isolation tests assert that document content is preserved.
